# Security Policy

If you find a security issue in DialedUp, please report it privately. Use GitHub's **Report a vulnerability** button under this repository's **Security** tab. Please don't open a public issue.

Include:

- the steps to reproduce the issue
- the impact, for example what data could be read or changed

We aim to respond within a few days. Please don't access other members' data or disrupt the service while testing.
